# Typical AI adoption

::body::
<div class="rows large titles">
  <div class="row"><span class="n">1</span><h3>Everyone got the tools</h3></div>
  <div class="row"><span class="n">2</span><h3>A few people use AI and build tools <span class="row-label">the vibecoders &amp; toolsmiths</span></h3></div>
  <div class="row"><span class="n">3</span><h3>Everybody starts to build the same tools</h3></div>
  <div class="row"><span class="n">4</span><h3>Chaos and confusion on how to integrate</h3></div>
</div>
<p class="kicker big">Our learning: we need a company-wide <em>AI orchestration layer</em>.</p>

::notes::
Ninety seconds, and this is our answer to the question above. We did the obvious thing first: give everybody AI. Copilot, then ChatGPT for the whole team, then Claude Code. Real money, real rollout, a lot of enthusiasm from me. What happened: a few people started using AI seriously and building their own tools — the vibecoders and the toolsmiths, the hands that went up in track 2. Then everybody started building the same tools over again, each in their own corner, and nobody knew how any of it was supposed to fit together. Real money, real enthusiasm, real chaos. Say the line that is no longer on the slide, out loud: access is not adoption. Then the learning, and it is the sentence the whole talk hangs on: we needed a company-wide AI orchestration layer. Everything after this slide is what we built.
